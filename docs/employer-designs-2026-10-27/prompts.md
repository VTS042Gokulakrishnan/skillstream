Generated using the built-in image generation tool. Concept mockups with fictional sample data; not implemented application screens.

## Shared design prompt

Use case: ui-mockup. Create a polished high-fidelity desktop web application design image for SkillStream employer recruitment platform. Single screen, landscape 1600x1000 composition, crisp readable text, flat front-on UI screenshot, no device frame or perspective. Cohesive design system: deep navy #102747 sidebar 230px, white top header 72px, icy gray #F5F8FC canvas, vivid blue #0785F9 primary actions, cyan accents, white cards with fine blue-gray borders, 12px corners, restrained shadows, Inter-like typography, generous whitespace and compact professional data density. SkillStream text wordmark. Shared sidebar grouped Workspace (Dashboard, Manage jobs, All applicants), Talent (Resume search, AI resume search, Shortlisted, Saved resumes, Interviews, AI fitment), Organization (Profile, Users, Billing). Header workspace name, search, bell, avatar AK. Highlight correct current page. Use fictional sample data and small Sample data caption. Content must be practically usable, carefully aligned and attractive. No decorative marketing illustrations.
